# C and Python fundamentals

An interactive, self-contained study course (C 1–3, Python 1–3): lessons, a step-through
memory view, quizzes, predict-the-output items and coding tasks with reference solutions.
One file, no dependencies, no build step. Task answers are saved in your browser's
localStorage.

## Publish with GitHub Pages

1. Create a new repository (for example `c-python-course`).
2. Upload `index.html` and `README.md` to the repository root.
3. Settings > Pages > Build and deployment > Source: **Deploy from a branch**,
   branch **main**, folder **/ (root)**, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/c-python-course/`.

On iPhone, Safari can do all of this through the GitHub website (Add file > Upload files).
Open the Pages URL in Safari and use Share > Add to Home Screen to launch it like an app.

## Adding lessons

Lessons are entries in the `L` array inside `index.html`. Copy an existing entry and edit it.
